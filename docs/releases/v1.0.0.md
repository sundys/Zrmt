# Zrmt v1.0.0

ZCode 移动远程控制链接管理器首个正式版本。

## ✨ 功能特性

- **卡式管理**：首页每张卡片对应一台电脑，粘贴远程链接自动解析并展示电脑名称（`name` 参数）与 ZCode 版本号（`app_version` 参数）
- **一键远程**：点击卡片即在应用内打开 zcode 操作界面（系统 WebView），视口自适应，自动适配手机屏幕
- **实时解析预览**：输入即校验，实时预览识别结果；链接缺少 `sid`/`hash` 等参数时明确提示无效
- **便捷管理**：长按卡片可打开 / 编辑 / 复制链接 / 删除；支持系统"分享链接"直接接入 Zrmt 快速添加
- **WebView 增强**：电脑版 / 手机版 UA 一键切换、加载失败重试页、摄像头与麦克风权限透传、远程操作期间保持屏幕常亮

## 📦 下载安装

Android 8.0（API 26）及以上。按手机 CPU 架构选择 APK，**现代手机（小米、三星、Pixel 等）选 arm64-v8a**：

| 文件 | 适用架构 |
|---|---|
| `app-arm64-v8a-release.apk` | 64 位（主流机型） |
| `app-armeabi-v7a-release.apk` | 32 位（老旧设备） |

## 🔧 技术说明

- 纯 Android 原生框架实现（Activity + WebView + SharedPreferences），**零第三方依赖**，APK 仅约 635KB
- 链接数据仅保存在本机，不上传任何信息
- 本版本 APK 由 GitHub Actions 构建并使用正式密钥签名（密钥通过仓库 Secrets 注入，不入库）
