# Zrmt v1.1.0

新增设置中心（主题切换 + 应用内更新），并完善网页文件上传。

## ✨ 新功能

- **设置中心**：首页右上角齿轮图标进入
  - **三种主题模式**：日间模式 / 夜间模式 / 跟随系统，全站界面即时切换，深浅色资源自动适配
  - **检测更新**：一键检查 GitHub 最新 Release，发现新版本弹窗展示更新说明，确认后应用内下载
  - **下载进度**：实时进度条与百分比 / 传输量显示，支持取消
  - **自动安装**：下载完成后自动跳转系统安装器；首次安装会引导授予"安装未知应用"权限
  - **GitHub 代理加速**：检测与下载按「自定义代理前缀 → 直连 → 内置镜像（gh-proxy / ghfast / ghproxy）」自动探测，全部通道失败会提示配置自定义代理；设置页可填入自己的加速前缀
- **网页文件上传**（v1.0.1）：WebView 内选择附件/图片接入系统文件选择器，支持多选与类型过滤
- **手机存储权限**：为网页上传补充媒体读取权限

## 🔧 优化

- 深浅色主题由 values / values-night 双套资源驱动，对话框、菜单随主题联动
- 更新 APK 经应用内置 ContentProvider 提供给系统安装器，无需外部存储权限
- 纯 Android 原生框架实现，**保持零第三方依赖**

## 📦 下载安装

Android 8.0+。主流 64 位手机选 `app-arm64-v8a-release.apk`，老旧 32 位设备选 `app-armeabi-v7a-release.apk`。

> 升级提示：从 v1.0.0 直接覆盖安装即可（同一签名密钥）；应用内"检测更新"也可自动完成上述流程。
