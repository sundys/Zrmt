# Zrmt v1.1.2

设置页交互优化与主题选择修正。

## ✨ 优化

- **主题颜色改为弹出选择**：设置页"外观"分组下新增「主题颜色」菜单行，副标题实时显示当前模式，点击弹出单选对话框在 跟随系统 / 日间模式 / 夜间模式 之间切换，选择后立即生效
- 原内嵌的三个单选项移除，设置页更紧凑

## 🐛 修复（含 v1.1.1 未发布内容）

- **主题单选项状态不清晰**：修复 `buttonTint` 单色着色导致选中/未选中圆圈同色难辨的问题（日间模式下尤为明显），改用自定义选中态图形（未选中灰色圆环 / 选中蓝色圆环+实心点），并配合选中项文字蓝色加粗

## 📦 下载安装

Android 8.0+。主流 64 位手机选 `app-arm64-v8a-release.apk`，老旧 32 位设备选 `app-armeabi-v7a-release.apk`。也可在应用内 设置 → 检测更新 一键升级。
