# Zrmt v1.1.3

修复设置页 GitHub 代理输入对话框的排版问题。

## 🐛 修复

- **代理输入框排版错乱**：此前对话框输入框为代码动态创建的裸 EditText，直接嵌入对话框导致贴边无边距、内外 padding 叠加错位，且 `setMessage` 与 `setView` 同用在部分系统版本上布局挤压。现改为规范布局文件：说明文字置于输入框上方、输入框采用与应用内一致的圆角描边样式（bg_input）、单行输入、宽度随对话框留白自适应。

## 📦 下载安装

Android 8.0+。主流 64 位手机选 `app-arm64-v8a-release.apk`，老旧 32 位设备选 `app-armeabi-v7a-release.apk`。也可在应用内 设置 → 检测更新 一键升级。
